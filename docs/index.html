說不出口的句子

用說的：手機切到英文鍵盤點麥克風，電腦按 Win + H，說完再送出。

教練說話程度

A2 用很短的句子；B1 日常用語；B2 像母語同事一樣自然。

職業、興趣、最近在忙的事，中英文都可以。教練會用來找話題。

朗讀

自動選擇時先用這台裝置上的聲音（沒有這個口音的，就用裝置上其他的英文聲音）。標「線上」的聲音比較自然，但要唸的文字會送到 Microsoft 或 Google 的服務，在中國大陸可能連不上。

這個瀏覽器不支援朗讀。

麥克風

填了之後，這個網頁也能用 AI 教練。金鑰只存在這個瀏覽器，只會送到 Anthropic 的 API；用量算在你的 Claude API 帳單。公用電腦不要存。

直接打開檔案時不能存 API 金鑰：這台電腦上其他的網頁檔案也讀得到它。要用 AI 教練，請改開 GitHub Pages 的網址，或從 Claude 的連結開啟。
