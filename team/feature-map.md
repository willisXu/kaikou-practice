# 功能地圖

verifier 靠這份文件知道每個功能怎麼觸發、怎麼判斷正確。改動使用者看得到的功能，就要更新對應的列；缺少這一列，verifier 會判定「無法驗證」。

段落編號對應 `test/run.js` 每段的標題，用 `npm test -- <段落>` 只跑那一段。

| 功能 | 怎麼觸發 | 預期結果 | 自動化檢查 |
|---|---|---|---|
| 今日：打卡與每日菜單（Claude 版，手機） | 在 Claude 裡打開，勾選菜單項目 | 月曆蓋章、分鐘數與連續天數更新，存到雲端 | `npm test -- 1` |
| 深色模式桌面版 | 桌面寬度、系統深色模式 | 版面與對比正常 | `npm test -- 2` |
| GitHub Pages／直接開檔（手機） | 用瀏覽器打開 `docs/index.html` | 一次只顯示一個分頁、沒有左右捲動，資料存在這個瀏覽器 | `npm test -- 3` |
| 網頁版 AI 教練（自己的 API 金鑰） | GitHub Pages 網址上，在設定輸入金鑰 | 串流回覆、錯誤依類型說明，金鑰不存進檔案版 | `npm test -- 3b` |
| 雲端失敗情況 | 寫入失敗、沒有權限、一打開就連不上雲端 | 自動重試、改存瀏覽器、之後補存，不蓋掉雲端資料 | `npm test -- 4` |
| 句子複習、影子跟讀、4/3/2 | 收藏分頁與今日的練習工具 | 間隔複習排程正確，計時與跟讀正常 | `npm test -- 5` |
| 麥克風：聽寫與唸一次 | GitHub Pages 上按麥克風 | 聽寫進輸入框，唸一次的比對容忍數字與拼法差異 | `npm test -- 6` |
| 語音對話 | GitHub Pages 上開「語音對話」 | 教練唸完才開麥克風，說完倒數後自動送出 | `npm test -- 6b` |
| 沒有朗讀聲音的瀏覽器 | 有語音辨識但沒有朗讀聲音 | 不提供語音對話，其他功能照常 | `npm test -- 6c` |
| 備份檔 | 設定裡匯出、匯入 | 網頁版與 Claude 版互相合併，壞掉的檔案帶不進奇怪的資料 | `npm test -- 7` |
| 加到主畫面、離線開啟 | GitHub Pages 網址加到主畫面 | manifest 與圖示正確，離線也能打開，網站更新後換新版 | `npm test -- 8` |
| 字型服務很慢 | Google Fonts 不回應 | 頁面照常用系統字型打開 | `npm test -- 9` |
| 句型更正 | 教練分頁對話 | 每輪最多 2 個更正，改過兩次的句型先給提示 | `npm test -- 10` |
| 情境與語塊 | 角色扮演選單、救急包 | 任務與說法顯示正確，可以收藏 | `npm test -- 11` |
| 送給教練的內容、效能與安全 | 長對話、重新讀取 | 只送必要的內容，打開頁面不會自己問教練，HTML 當成文字 | `npm test -- 12` |
| 每日一課 | 今日 →「今天的課」 | 一課從頭到尾可完成，進度存好、讀回 | `npm test -- 13` |
| 發布腳本 | `bash test/publish.sh` | 各種 Git 情況都照預期發布或停下 | `bash test/publish.sh` |
| Claude Artifact 片段 | `npm run artifact -- <輸出檔>` | 沒有 `<html>`、`<head>`、`<body>` 外框與 `data-pages-only` 標籤 | `npm test -- 8` |
