# 測試規則

- 瀏覽器測試在 `test/run.js`，按段落組織（`SECTIONS`）。新增的檢查放進對應段落；新段落要加進 `SECTIONS`。
- README 記著檢查總數（「共 N 項檢查」）；增減檢查時一起更新。
- `test/mock.js` 模擬 `window.claude`，`test/speech.js` 模擬語音。改到平台介面時，一起更新它們。
- 測試描述行為：斷言畫面、資料與焦點，不斷言內部呼叫次數。
- 不修改既有斷言來讓測試通過，除非任務明確要求改規格。
- 修一個 bug，就加一個在修好之前會失敗的檢查。
- 測試裡的 API 金鑰用拼出來的假字串；架構檢查會擋下真的金鑰格式。
- `team/guardrails/` 放證明護欄有效的測試：每條規則至少一個「擋下壞寫法」和一個「放行好寫法」。
