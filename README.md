# 開口練習室

英文口說練習的網頁 App：每日練習菜單與打卡、AI 對話教練、練習紀錄與收藏。整個程式就是 `docs/index.html` 一個檔案（HTML、CSS、JavaScript 寫在一起），不需要建置，部署在 GitHub Pages。

| 分頁 | 內容 |
| --- | --- |
| 今日 | 20／60 分鐘菜單打勾（影子跟讀、AI 對話、語塊複習、聽 Podcast）；每週真人家教與 4/3/2 錄音；每月進度錄音；「說不出口的句子」隨手記，之後可以交給教練 |
| 教練 | 自由聊天、情境角色扮演、中翻英口說。每句話下面附更自然的說法，可以朗讀、看中文、要提示；按「結束並複習」產生這次的摘要、要注意的地方與值得收藏的說法，並自動打勾、記錄分鐘數 |
| 紀錄 | 月曆蓋章、練習天數、達標天數、專注分鐘、連續天數，以及每次複習的摘要 |
| 收藏 | 開口救急包 12 句、收藏的說法；可以複製成 Anki 匯入格式 |

頁面本身不收音，用系統的語音輸入練「說」：Windows 按 <kbd>Win</kbd> + <kbd>H</kbd>；手機把鍵盤切到英文、點麥克風。先大聲說，再送出。

## 程式重點（給維護的人）

**平台介面**：在 Claude 裡用 `window.claude.use('db' | 'sample' | 'user')` 取得資料庫、AI 與使用者 id。沒有 `window.claude` 時改用 localStorage（鍵名 `kaikou:<文件名>`）；連 localStorage 都不能用時只存在記憶體，畫面會提醒。

**資料**（每位使用者自己的 `data/users/<id>/` 底下）

| 文件 | 內容 | 寫法 |
| --- | --- | --- |
| `settings` | 練習量、程度、自我介紹、口音、語速、自動朗讀 | 只更新改到的欄位 |
| `log-YYYY-MM` | `days[日期] = { plans, items, coach }`、`monthRecord` | 只送出改到的項目。`plans` 以「權重 → 方案」存：建立當天的裝置寫預設值（權重 0），手動選擇寫在時間戳記下，權重最高的生效，所以還沒更新的裝置不會蓋掉另一台的選擇。`coach` 以對話 id 記分鐘，重送不會重複累加 |
| `phrases`、`inbox`、`sessions-YYYY-MM` | 以 id 為鍵的 map | 用 `update` 合併，刪除寫 `null`，兩台裝置各自新增不會互相覆蓋。舊版的 `items` 陣列仍讀得到 |
| `chat` | 進行中的對話（保留最近 60 句） | 整份寫入；複習存好之後才標記結束，而且只在雲端存的還是同一個對話時才標記 |

- 寫入：每個文件一個佇列、依序寫入。失敗的變更會保留，以 3 秒起、最長 60 秒的間隔自動重試，右上角顯示「同步失敗，會自動再試」。`update` 對「文件不存在」以外的錯誤（例如文件太大）不會改用整份覆寫。
- 重新讀取：切回頁面、視窗取得焦點（15 秒內不重複）與畫面開著時每 3 分鐘一次。讀取期間本機有寫入就丟棄這次結果、下次再讀；從沒載入成功的月份則和本機的變更合併。
- AI 教練：`sample()` 串流回覆。教練的格式是「英文回覆、`###`、每行一個 JSON 更正」，解析時容忍程式碼區塊、`##`、彎引號與被截斷的 JSON（截斷的部分不會顯示）。提示與複習用 `sample()` 取得 JSON 文字再解析，並關閉快取，讓「再試一次」真的重新產生。被拒絕的句子不會再送出，也不算在句數裡。
- 無障礙：重繪時保留鍵盤焦點（`data-fk`）、`#sr-live` 朗讀狀態、分頁可用方向鍵切換、對話泡泡標示語言。

## 測試

`test/` 是 Playwright 瀏覽器測試：`mock.js` 模擬 `window.claude`（記憶體資料庫與固定的 AI 回覆），`run.js` 用手機淺色、桌機深色、沒有 `window.claude` 三種情境跑過打卡、對話、提示、翻譯、複習、紀錄與收藏，截圖存到 `test/shots/`。

```
npm install
npx playwright install chromium
npm test
```

最後印出 `ERRORS: none` 表示沒有頁面錯誤。

## 更新與發布

1. 修改 `docs/index.html`（VS Code、Claude Code 都可以）
2. 點 `推送到GitHub.bat`：先同步 GitHub 上的版本，再 commit 並 push；GitHub Pages 約 1 分鐘後更新
3. 完整版：把改好的檔案交給 Claude，重新發佈到同一個 Artifact 連結

需求：Git（推送用）；跑測試另需 Node.js 18 以上。
