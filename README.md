# 開口練習室

英文口說練習的網頁 App：每日練習菜單與打卡、AI 對話教練、句子間隔複習、影子跟讀、4/3/2 計時、練習紀錄與收藏。整個程式就是 `docs/index.html` 一個檔案（HTML、CSS、JavaScript 寫在一起），不需要建置，部署在 GitHub Pages。

| 分頁 | 內容 |
| --- | --- |
| 今日 | 20／60 分鐘菜單打勾（影子跟讀、AI 對話、語塊複習、聽 Podcast）；每週真人家教與 4/3/2；每月進度錄音；「說不出口的句子」隨手記，之後可以交給教練。影子跟讀和 4/3/2 可以直接在這裡練（見下方） |
| 教練 | 自由聊天、情境角色扮演、中翻英口說。每句話下面附更自然的說法，可以朗讀、唸一次檢查、看中文、要提示；按「結束並複習」產生這次的摘要、要注意的地方與值得收藏的說法，並自動打勾、記錄分鐘數 |
| 紀錄 | 月曆蓋章、練習天數、達標天數、專注分鐘、連續天數，以及每次複習的摘要 |
| 收藏 | 每日句子複習（間隔重複）、開口救急包 12 句、收藏的說法；可以複製成 Anki 匯入格式 |

### 練習工具

- **句子複習**（收藏分頁，今日的「語塊複習」也會帶過去）：看提示先大聲說英文，再翻面對答案，按「忘了／有點卡／記得」。提示是收藏時的中文；從「更自然的說法」收藏的句子，會給你原本的說法，請你說出更好的版本。新句子「記得」2 天後再出現、「有點卡」1 天，之後每次「記得」間隔約變成 2.5 倍（「有點卡」1.2 倍），「忘了」這一輪會再出現一次。每天最多加入 10 句新句子，一輪最多 20 句。一輪做完自動打勾「語塊複習」。電腦上可以用空白鍵翻面、1／2／3 評分。
- **影子跟讀**（今日 → 影子跟讀 →「在這裡跟讀」）：請教練依你的程度寫 6 或 10 句的短文，或貼上自己的英文逐字稿（最多 30 句）。可以「聽一句、跟一句」（每句後面留出跟讀的時間）或連續播放，可調語速（0.5–1.2 倍）、隱藏稿子、看中文。按「完成今天的跟讀」會打勾並記下這篇練了幾天，同一篇建議練 3–5 天。最近 12 篇會留著。
- **4/3/2**（今日 → 4/3/2 →「開始 4/3/2」）：同一個主題講 4、3、2 分鐘，計時可暫停，時間到會響（手機會震動），三次講完自動打勾本週的 4/3/2。可以請教練給 3 個重點和用得上的說法。網頁版可以每次都錄音，三次講完一起聽、下載（錄音不會存起來）。計時中切到別的分頁或手機鎖定會自動暫停；瀏覽器支援時，計時中螢幕會保持開著。
- **麥克風**（只有網頁版）：教練的輸入框旁有麥克風鍵，說完會自動停，文字進輸入框，確認後再送出。中翻英練習先聽中文，教練給說法之後自動改聽英文（輸入框旁的「中／EN」可以切換）。每句「更自然的說法」、收藏、複習卡和跟讀句子旁都有「唸一次」：唸給它聽，沒聽出來的字會用紅色波浪線標出。詳見下方「麥克風」。

## 麥克風（網頁版）

- 用的是瀏覽器內建的語音辨識：Chrome 和 Edge 會把聲音送到它們的服務（Chrome 是 Google），Safari 用 Apple 的聽寫。第一次用時瀏覽器會問是否允許麥克風。
- **連不上服務時**（例如在中國大陸用 Chrome、沒有連 VPN）：會顯示說明，這次先把麥克風關掉，改用系統的語音輸入；網路正常後到設定按「重新啟用麥克風」。
- **瀏覽器不允許時**：說明怎麼在網站設定允許，麥克風鍵會收起來，之後打開也會記得（30 天）；允許之後到設定按「重新啟用麥克風」。
- **iPhone**：要在 Safari 裡用，並開啟 Siri 與聽寫。從主畫面打開的版本，iPhone 不提供語音辨識，所以不會出現麥克風鍵。
- 播放跟讀或朗讀時一按麥克風，播放會先停，免得錄到自己的喇叭聲。

## 備份與搬移

設定 →「匯出備份檔」存成 `kaikou-backup-日期.json`，內容是設定、打卡、收藏、隨手記、句子複習排程和跟讀短文（不含進行中的對話，也不含 API 金鑰）。在另一台裝置或另一個版本按「匯入備份檔」，會先列出檔案裡有什麼，按「合併到這裡」才合併：

- 只會新增，不會刪掉任何東西；同一天兩邊的打勾都保留；同一句的複習排程取最後複習的那一邊；設定只在這裡還是預設值時才匯入（不然只補上空白的「關於我」）。
- 收藏、隨手記、跟讀短文已經滿了，放不下的就不加，並在提示裡說明。
- 重複匯入同一個檔案不會多出東西。這裡有資料還讀不到（雲端暫時連不上）時會先不合併，檔案留著，等一下再按一次。
- 在 Claude 裡匯出時，會先請你確認下載；匯出的是雲端上每個月的資料。

## 加到主畫面（GitHub Pages）

設定裡的「加到主畫面」有說明：Android 和電腦上的 Chrome、Edge 有「安裝到主畫面」按鈕；iPhone 用 Safari 的「分享」→「加入主畫面」。裝好之後像 App 一樣從圖示打開，沒有網路也能打開頁面（`docs/sw.js`：頁面先向網路拿最新版，4 秒內沒有回應就用上次存的那份）。iPhone 從主畫面打開時，資料可能和 Safari 分開存放，請用備份檔搬過去，API 金鑰也要重新輸入。

## 在網頁版用 AI 教練（自己的 Claude API 金鑰）

1. 到 [Claude Console](https://platform.claude.com) 登入，先在 Settings → Billing 儲值，再到 Settings → API keys 按 Create key。金鑰只會顯示一次，開頭是 `sk-ant-api`。
2. 打開 GitHub Pages 網址，按右上角的設定，在「Claude API 金鑰」貼上、按「儲存」。
3. 回到「教練」分頁開始對話。

- **費用**：對話、提示、翻譯用 Claude Haiku 5.5（`claude-haiku-5-5`），「結束並複習」用 Claude Sonnet 5.5（`claude-sonnet-5-5`），依實際用量計費。可以在 Claude Console 設定花費上限。
- **安全**：金鑰只存在這個瀏覽器（localStorage 的 `kaikou:api-key`），只送到 `api.anthropic.com`，不會存進雲端資料或 git。畫面上只顯示最後 4 碼。金鑰在瀏覽器裡，就可能被這個網域的其他頁面讀到：`willisxu.github.io` 底下的其他 GitHub Pages 專案和這個頁面共用同一份 localStorage。所以只在自己的裝置存，公用電腦不要存。
- **外流時**：到 Console 的 API keys 停用或刪除那把金鑰，再建一把新的。
- 「清除這個瀏覽器裡的練習資料」不會刪掉金鑰；要刪金鑰，按設定裡的「移除金鑰」。
- 在 Claude 裡開啟時不需要金鑰，設定裡也不會出現這個欄位（Claude 裡的頁面不能連到外部網站）。

## 程式重點（給維護的人）

**一個檔案、兩個地方用**：`docs/index.html` 是完整的 HTML 文件，GitHub Pages 和直接開檔都用它。Claude 的 Artifact 會自己包上 `<!doctype>`、`<html>`、`<head>`、`<body>`，所以發佈到 Claude 時要用 `tools/artifact.js` 轉成頁面片段（`npm run artifact -- 輸出檔`），拿掉這幾層外框，也拿掉只給 GitHub Pages 用、標了 `data-pages-only` 的標籤（manifest、主畫面圖示、theme-color），其餘內容不變。主畫面圖示用 `node tools/make-icons.js` 產生（需要 Noto Serif CJK TC 字型）。

**字型不擋畫面**：Google Fonts 的樣式表先以 `media="print"` 載入，到了才在程式裡換成 `all`，所以字型服務很慢或連不上時（例如在中國大陸），頁面照常用系統字型打開。

**平台介面**：在 Claude 裡用 `window.claude.use('db' | 'sample' | 'user' | 'downloads')` 取得資料庫、AI、使用者 id 與下載（匯出備份檔）；`window.claude.hot` 用來在頁面更新時保留目前的分頁與草稿。沒有 `window.claude` 時改用 localStorage（鍵名 `kaikou:<文件名>`）；連 localStorage 都不能用時只存在記憶體，畫面會提醒。

**網頁版的 AI**：沒有 `window.claude`、但存了 API 金鑰時，`apiSample()` 取代 `sample()`，介面相同（回傳 `{ text, truncated }`、`onText` 串流、`signal` 停止）。它直接呼叫 Messages API（`stream: true`，標頭 `x-api-key`、`anthropic-version: 2023-06-01`、`anthropic-dangerous-direct-browser-access: true`），把同一方連續的話合併成一則。錯誤對應：401／403 → 金鑰無效，額度不足 → 請儲值，404 → 模型已停用，429 → 用量上限，529 → 太忙，這些都會顯示中文說明；金鑰、額度與模型的問題不提供「重新回覆」。模型名稱在 `API_MODELS`，模型停用時改這裡。

**資料**（每位使用者自己的 `data/users/<id>/` 底下）

| 文件 | 內容 | 寫法 |
| --- | --- | --- |
| `settings` | 練習量、程度、自我介紹、口音、語速、自動朗讀 | 只更新改到的欄位 |
| `log-YYYY-MM` | `days[日期] = { plans, items, coach }`、`monthRecord` | 只送出改到的項目。`plans` 以「權重 → 方案」存：建立當天的裝置寫預設值（權重 0），手動選擇寫在時間戳記下，權重最高的生效，所以還沒更新的裝置不會蓋掉另一台的選擇。`coach` 以對話 id 記分鐘，重送不會重複累加 |
| `phrases`、`inbox`、`sessions-YYYY-MM` | 以 id 為鍵的 map | 用 `update` 合併，刪除寫 `null`，兩台裝置各自新增不會互相覆蓋。舊版的 `items` 陣列仍讀得到。收藏的「更自然的說法」多存一個 `was`（原本的說法） |
| `srs` | `map[收藏 id] = { d: 下次日期, i: 間隔天數, r: 連續記得次數, l: 忘記次數, f: 第一次複習, t: 最後複習 }` | 每評一張卡寫那一筆；刪除收藏時寫 `null`。排程比收藏的時間還舊（同一句刪掉後又收藏）就當新句子。還讀不到 `srs` 時不開始複習，以免蓋掉排好的時間；暫時存在瀏覽器、之後上傳的排程，只在比雲端上的新時才送出 |
| `shadow` | `{ cur, map[id] = { title, level, at, src, sents: [{ en, zh }], days } }` | 最多 12 篇、約 120 KiB，新增時移除最舊的；`days` 記練過的日期 |
| `chat` | 進行中的對話（最近 60 句，太長時再少一些） | 整份寫入；複習存好之後才標記結束，而且只在雲端存的還是同一個對話時才標記 |

- **大小**：平台限制每份文件 256 KiB，程式讓每份都保持在約 160 KiB 以下：每個月的複習最多 150 次，超過大小時先移除該月最舊的；收藏最多 600 句，滿了會請使用者先刪；複習與收藏的各欄位有長度上限。
- **寫入**：每個文件一個佇列、依序寫入。暫時性的失敗（`unavailable`、`resource_exhausted`）會保留變更，以 3 秒起、最長 60 秒的間隔自動重試，右上角顯示「同步失敗，會自動再試」。雲端空間已滿或文件太大時不會一直重試，提醒使用者刪東西，刪除後自動再存。沒有寫入權限（小文件被拒）、權限被收回或資料庫無法使用時，這次改存在這個瀏覽器（和瀏覽器裡已有的資料合併，不會蓋掉）；沒有權限的非擁有者下次開啟也直接用瀏覽器儲存。下次能用雲端時，今日頁會提醒「這台裝置上有…還沒存到雲端」，按「存到雲端」以合併的方式上傳。
- **重新讀取**：切回頁面、視窗取得焦點（15 秒內不重複）與畫面開著時每 3 分鐘一次；內容沒變就不重畫，正在用注音或拼音輸入時等輸入完再重畫。讀取期間本機有寫入就丟棄這次結果、下次再讀；從沒載入成功的月份則和本機的變更合併。瀏覽器模式下，同一個瀏覽器的其他分頁存檔時會立刻反映，寫入時也會合併其他分頁的變更。
- **AI 教練**：`sample()` 串流回覆，只在使用者按下按鈕時呼叫。教練的格式是「英文回覆、`###`、每行一個 JSON 更正」，解析時容忍程式碼區塊、`##`、彎引號與被截斷的 JSON（截斷的部分不會顯示）。提示與複習用 `sample()` 取得 JSON 文字再解析，並關閉快取，讓「再試一次」真的重新產生。被拒絕的句子不會再送出，也不算在句數裡。
- **無障礙**：重繪時保留鍵盤焦點（`data-fk`）、`#sr-live` 朗讀狀態、分頁可用方向鍵切換、對話泡泡標示語言。跟讀播放時只更新目前句子的標示，不重畫整頁（拖曳語速、螢幕閱讀器的位置都不會被打斷）。
- **語音**：語音辨識一次只跑一個（`micStart`／`micStop`），用 `continuous: false`，停下來就結束；開始前會先停掉朗讀與跟讀播放。「唸一次」的比對不分大小寫與標點，縮寫（I'm = I am）和數字寫法（two = 2）不同也算對。在 Claude 裡、iPhone 主畫面版不提供麥克風；瀏覽器拒絕時記在 `kaikou:mic-off`（30 天），連不上服務只關掉這一次。4/3/2 用 `MediaRecorder` 錄音（只留在記憶體），兩次之間會放開麥克風；計時中用 Wake Lock 讓螢幕不關，切走或鎖定會自動暫停。

## 測試

`test/run.js` 是 Playwright 瀏覽器測試，任何一項檢查失敗都會以非 0 結束碼結束：

- 在 Claude 裡（`test/mock.js` 模擬 `window.claude`，包含資料庫的合併規則與大小限制、讀取失敗、列出文件與下載）：打卡蓋章、對話與更正、提示、翻譯、結束並複習、紀錄、收藏、問教練、放棄對話、設定；句子複習（排程、自動打勾、原本的說法、還讀不到排程時不開始）、教練寫跟讀短文與播放、4/3/2 計時（用 Playwright 的時鐘快轉）。
- GitHub Pages：直接打開 `docs/index.html`，用手機模擬，確認一次只顯示一個分頁、沒有左右捲動，同一個瀏覽器開兩個分頁不會互相蓋掉。
- GitHub Pages 加 API 金鑰：用 `page.route` 模擬 `api.anthropic.com`（串流回覆與 401），金鑰是測試用的假字串，不會連到真的 API。檢查設定欄位、請求標頭與模型、對話與複習、金鑰無效的說明、清除練習資料時保留金鑰、移除金鑰後另一個分頁也停用。
- 失敗情況：寫入失敗後自動重試、沒有寫入權限時改存瀏覽器（以及之後再存回雲端）、同步中途停止後下次上傳、被拒絕的句子、停止回覆、雲端空間已滿。
- 麥克風：`test/speech.js` 取代瀏覽器的語音辨識與朗讀（無頭瀏覽器沒有真的麥克風和聲音），檢查聽寫進輸入框、中翻英的語言切換、唸一次的比對、連不上服務與不允許時的處理、跟讀播放遇到麥克風會先停。
- 備份檔：網頁版匯出（經由本機 http 伺服器，像 GitHub Pages 一樣）、匯入 Claude 版並合併、重複匯入、還讀不到資料時先不合併、Claude 版經由下載匯出。
- 加到主畫面：manifest 與圖示、service worker 讓頁面離線也能打開、開過其他檔案也不會蓋掉存下來的頁面；Claude 版片段不帶這些標籤。
- 字型：字型服務一直不回應時，頁面照常打開。
