# 開口練習室

英文口說練習的網頁 App：每日練習菜單與打卡、AI 對話教練（網頁版可以用語音對話）、句子間隔複習、發音重點練習、影子跟讀、4/3/2 計時、練習紀錄與收藏。整個程式就是 `docs/index.html` 一個檔案（HTML、CSS、JavaScript 寫在一起），不需要建置，部署在 GitHub Pages。

| 分頁 | 內容 |
| --- | --- |
| 今日 | 20／60 分鐘菜單打勾（影子跟讀、AI 對話、語塊複習、聽 Podcast）；每週真人家教與 4/3/2；每月進度錄音；「說不出口的句子」隨手記，之後可以交給教練。影子跟讀和 4/3/2 可以直接在這裡練（見下方） |
| 教練 | 自由聊天、情境角色扮演、中翻英口說。每句話下面附更自然的說法，可以朗讀、唸一次檢查、看中文、要提示；網頁版可以開「語音對話」，像講電話一樣不用碰螢幕。按「結束並複習」產生這次的摘要、要注意的地方與值得收藏的說法，並自動打勾、記錄分鐘數 |
| 紀錄 | 月曆蓋章、練習天數、達標天數、專注分鐘、連續天數，以及每次複習的摘要 |
| 收藏 | 每日句子複習（間隔重複）、發音重點練習 8 組、開口救急包 12 句、收藏的說法；可以複製成 Anki 匯入格式 |

### 練習工具

- **句子複習**（收藏分頁，今日的「語塊複習」也會帶過去）：看提示先大聲說英文，再翻面對答案，按「忘了／有點卡／記得」。提示是收藏時的中文；從「更自然的說法」收藏的句子，會給你原本的說法，請你說出更好的版本。新句子「記得」2 天後再出現、「有點卡」1 天，之後每次「記得」間隔約變成 2.5 倍（「有點卡」1.2 倍），「忘了」這一輪會再出現一次。每天最多加入 10 句新句子，一輪最多 20 句。一輪做完自動打勾「語塊複習」。電腦上可以用空白鍵翻面、1／2／3 評分。
- **影子跟讀**（今日 → 影子跟讀 →「在這裡跟讀」）：請教練依你的程度寫 6 或 10 句的短文，或貼上自己的英文逐字稿（最多 30 句）。可以「聽一句、跟一句」（每句後面留出跟讀的時間）或連續播放，可調語速（0.5–1.2 倍）、隱藏稿子、看中文。按「完成今天的跟讀」會打勾並記下這篇練了幾天，同一篇建議練 3–5 天。最近 12 篇會留著。
- **4/3/2**（今日 → 4/3/2 →「開始 4/3/2」）：同一個主題講 4、3、2 分鐘，計時可暫停，時間到會響、畫面也會閃一下（Android 手機還會震動；iPhone 開靜音時不會響，網頁也不能讓 iPhone 震動），三次講完自動打勾本週的 4/3/2。可以請教練給 3 個重點和用得上的說法。網頁版可以每次都錄音，三次講完一起聽、下載（錄音不會存起來）。計時中切到別的分頁或手機鎖定會自動暫停；瀏覽器支援時，計時中螢幕會保持開著。
- **語音對話**（只有網頁版，自由聊天與情境角色扮演）：在教練選單按「開始語音對話」，或對話中按「語音對話」。教練的回覆會唸出來，唸完自動開麥克風聽你說；你說完停一下，輸入框裡的文字倒數 2.5 秒就自動送出。倒數時麥克風還在聽，說到一半停頓、接著說下去，會接在後面一起送，不會只送半句。倒數時可以按「先不要送」（文字留在輸入框，可以改）或「現在送出」，按輸入框旁的麥克風表示還沒說完。打字、點輸入框、看提示、按喇叭或「唸一次」、打開設定、換分頁、鎖定手機都會先暫停，按「繼續說」接下去（暫停時教練的回覆到了，按「繼續說」會先唸出來再聽你說；教練正在說時打字，會等教練說完才停；說到一半被別的事打斷，還沒確定的字不會留下，再說一次不會重複；點輸入框則留下畫面上的字讓你改）；提示放進輸入框後直接唸出來，會換成你唸的版本。一直沒說話時會再聽兩次（給你想的時間），還是沒聲音就暫停。語音對話一定會唸教練的回覆，所以這時「自動朗讀」按鈕先收起來。按「放棄」「結束並複習」或語音條上的 × 結束。
- **發音重點練習**（收藏分頁）：說中文的人常混在一起的 8 組音：th（think／sink）、v（very／wery）、字尾子音（bag／back）、長短 i（sheep／ship）、æ 和 e（bad／bed）、s 和 sh（see／she）、n 和 ng（win／wing）、r 和 l（right／light）。每組有發音方法、6 對字、6 題的聽辨小測驗（播一個字，選你聽到哪一個）和 3 句練習句。網頁版可以對著麥克風唸一個字，看電腦聽到的是這個字、另一個字，還是聽不出來（同音的拼法也算對，例如 sea／see）；電腦常會往常見的字猜，結果當參考。每組的成績（最近 20 次唸字、上次聽辨）只存在這個瀏覽器（`kaikou:pron`），不會同步，也不在備份檔裡。
- **麥克風**（只有網頁版）：教練的輸入框旁有麥克風鍵，說完會自動停，文字進輸入框，確認後再送出。中翻英練習先聽中文，教練給說法之後自動改聽英文（輸入框旁的「中／EN」可以切換）。每句「更自然的說法」、收藏、複習卡和跟讀句子旁都有「唸一次」：唸給它聽，沒聽出來的字會用紅色波浪線標出。詳見下方「麥克風」。

## 麥克風（網頁版）

- 用的是瀏覽器內建的語音辨識：Chrome 和 Edge 會把聲音送到它們的服務（Chrome 是 Google），Safari 用 Apple 的聽寫。第一次用時瀏覽器會問是否允許麥克風。
- **連不上服務時**（例如在中國大陸用 Chrome、沒有連 VPN）：會顯示說明，這次先把麥克風關掉，改用系統的語音輸入；網路正常後到設定按「重新啟用麥克風」。
- **瀏覽器不允許時**：說明怎麼在網站設定允許，麥克風鍵會收起來，之後打開也會記得（30 天）；允許之後到設定按「重新啟用麥克風」。
- **iPhone**：要在 Safari 裡用，並開啟 Siri 與聽寫。從主畫面打開的版本，iPhone 不提供語音辨識，所以不會出現麥克風鍵。
- 播放跟讀或朗讀時一按麥克風，播放會先停，免得錄到自己的喇叭聲。語音對話也是等教練唸完才開麥克風。
- **語音對話在 iPhone 上**：有些瀏覽器要按一下才肯開始聽。教練唸完後如果停在「瀏覽器要你先按一下」，按「繼續說」就好，之後每一輪可能都要按一次。
- **在中國大陸**：Chrome 的語音辨識用 Google 的服務，沒有 VPN 時連不上，語音對話會關掉並說明。可以試試 iPhone 或 Mac 的 Safari（用 Apple 的聽寫）。

## 朗讀的聲音

Claude 版和網頁版都一樣：設定的「聲音」選「自動選擇」時，先用這台裝置上的聲音（有你選的口音就用那個口音，沒有就用裝置上其他的英文聲音），要唸的文字不會離開裝置。清單裡標「線上」的聲音（例如 Edge 的 Microsoft … Online、Chrome 的 Google 聲音）比較自然，但要唸的文字（教練的回覆、收藏的句子、跟讀短文）會送到 Microsoft 或 Google 的服務，在中國大陸可能連不上；裝置上沒有英文聲音時，自動選擇也只能用線上的。

## 備份與搬移

設定 →「匯出備份檔」存成 `kaikou-backup-日期.json`，內容是設定、打卡、收藏、隨手記、句子複習排程、對話複習（教練整理的摘要，含你在對話裡說過的句子）和跟讀短文（不含進行中的對話，也不含 API 金鑰）。在另一台裝置或另一個版本按「匯入備份檔」，會先列出檔案裡有什麼，按「合併到這裡」才合併：

- 只會新增，不會刪掉任何東西；同一天兩邊的打勾都保留；同一句的複習排程取最後複習的那一邊；設定只在這裡還是預設值時才匯入（不然只補上空白的「關於我」；在 Claude 裡但連不上雲端、畫面上是這個瀏覽器的資料時，不匯入設定）。
- 收藏、隨手記、跟讀短文或某個月的對話複習（每月最多 150 次，也不能太大）已經滿了，放不下的就不加，並在提示裡說明；這裡原有的不會被擠掉（剛好卡在大小上限時也一樣），提示也只算真的加進來的。
- 重複匯入同一個檔案不會多出東西。這裡有資料還讀不到（雲端暫時連不上）時會先不合併，檔案留著，等一下再按一次。
- 日期要是真的日期（2020 年起、不晚於明天），而且放在自己的月份裡；其他的略過，不會多出奇怪的月份。收藏的句子照這裡的規則收（同一句同一個 id，各欄位有長度上限）；每天的計畫只收合理的權重（0、-1 或不晚於明天的選擇時間），手做的檔案不能把某天的計畫永遠鎖住（已經存在雲端或瀏覽器裡的權重不看這台裝置的時鐘：時鐘較快的裝置存的選擇照樣算）。
- 在 Claude 裡匯出時，會先請你確認下載；匯出的是雲端上每個月的資料（以雲端存的版本為準，這台裝置還沒存好的變更、上次連不上雲端時留在這個瀏覽器還沒上傳的變更再合併上去）。這次一打開就連不上雲端，或雲端同步中途停止時，檔案裡只有這個瀏覽器的資料，匯出時會說明。讀不到雲端的文件清單時，匯出這台裝置載入的資料（還沒上傳的變更也加在上面），並說明。這個畫面不能下載檔案時（例如沒有允許下載），會直接說明，不會叫你一直再試。

## 加到主畫面（GitHub Pages）

設定裡的「加到主畫面」有說明：Android 和電腦上的 Chrome、Edge 有「安裝到主畫面」按鈕；iPhone 用 Safari 的「分享」→「加入主畫面」。裝好之後像 App 一樣從圖示打開，沒有網路也能打開頁面（`docs/sw.js`：頁面先向網路拿最新版並存一份；沒有網路、伺服器出錯或 4 秒內沒有回應，就用上次存的那份。網站搬家（轉址）時照網路的回應走，不會一直停在舊的頁面）。直接打開檔案時沒有這個功能。iPhone 從主畫面打開時，資料可能和 Safari 分開存放，請用備份檔搬過去，API 金鑰也要重新輸入。

## 在網頁版用 AI 教練（自己的 Claude API 金鑰）

1. 到 [Claude Console](https://platform.claude.com) 登入，先在 Settings → Billing 儲值，再到 Settings → API keys 按 Create key。金鑰只會顯示一次，開頭是 `sk-ant-api`。
2. 打開 GitHub Pages 網址，按右上角的設定，在「Claude API 金鑰」貼上、按「儲存」。
3. 回到「教練」分頁開始對話。

- **費用**：對話、提示、翻譯和 4/3/2 的重點用 Claude Haiku 5.5（`claude-haiku-5-5`），「結束並複習」和跟讀短文用 Claude Sonnet 5.5（`claude-sonnet-5-5`），依實際用量計費。可以在 Claude Console 設定花費上限。
- **安全**：金鑰只存在這個瀏覽器（localStorage 的 `kaikou:api-key`），只送到 `api.anthropic.com`，不會存進雲端資料或 git。畫面上只顯示最後 4 碼。金鑰在瀏覽器裡，就可能被這個網域的其他頁面讀到：`willisxu.github.io` 底下的其他 GitHub Pages 專案和這個頁面共用同一份 localStorage。所以只在自己的裝置存，公用電腦不要存。
- **只能在網址上用**：直接打開 `docs/index.html` 檔案時不能存金鑰（這台電腦上直接打開的網頁檔案共用同一份 localStorage，任何一個都讀得到它），所以那時沒有 AI 教練。以前在直接開檔時存過的金鑰，打開頁面時會自動移除，今日頁會提醒你到 Console 停用那把金鑰、再建一把新的。
- **在中國大陸或香港**：Claude API 不在這些地區提供服務（見 Anthropic 的 [Supported regions](https://platform.claude.com/docs/en/api/supported-regions)），直接連線時 API 會拒絕，教練會說明「所在地不在支援的地區」。要用就得連到支援地區的網路，換好網路後可以按「重新回覆」。
- **用量上限**：到了你在 Console 設定的花費上限，或帳戶等級的每月上限時，教練會說明是哪一種（前者到 Console 的 Billing 調高或取消，後者要等下個月 1 號或申請提高等級），不會說成金鑰有問題。
- **外流時**：到 Console 的 API keys 停用或刪除那把金鑰，再建一把新的。
- 「清除這個瀏覽器裡的練習資料」不會刪掉金鑰（也不會刪掉金鑰已移除的提醒）；要刪金鑰，按設定裡的「移除金鑰」。
- 在 Claude 裡開啟時不需要金鑰，設定裡也不會出現這個欄位（Claude 裡的頁面不能連到外部網站）。

## 程式重點（給維護的人）

**一個檔案、兩個地方用**：`docs/index.html` 是完整的 HTML 文件，GitHub Pages 和直接開檔都用它。Claude 的 Artifact 會自己包上 `<!doctype>`、`<html>`、`<head>`、`<body>`，所以發佈到 Claude 時要用 `tools/artifact.js` 轉成頁面片段（`npm run artifact -- 輸出檔`），拿掉這幾層外框，也拿掉只給 GitHub Pages 用、標了 `data-pages-only` 的標籤（manifest、主畫面圖示、theme-color），其餘內容不變。主畫面圖示用 `node tools/make-icons.js` 產生（需要 Noto Serif CJK TC 字型）。

**發佈到 Claude**：Artifact 要宣告 `db`、`sample`、`user`、`downloads` 四項能力（`capabilities: { db: {}, sample: {}, user: {}, downloads: true }`）。少了 `user` 就拿不到使用者 id，每次都會當成連不上雲端、只存在瀏覽器；少了 `downloads` 就不能匯出備份檔。更新時一律發佈到同一個網址（重新發佈會保留宣告過的能力）：新的網址是另一個空的雲端資料庫，原本的打卡和收藏不會跟過去。

**字型不擋畫面**：Google Fonts 的樣式表先以 `media="print"` 載入，到了才在程式裡換成 `all`，所以字型服務很慢或連不上時（例如在中國大陸），頁面照常用系統字型打開。

**平台介面**：在 Claude 裡用 `window.claude.use('db' | 'sample' | 'user' | 'downloads')` 取得資料庫、AI、使用者 id 與下載（匯出備份檔）；重新整理（包括頁面更新後重新載入）時，目前的分頁和還沒送出的文字存在 sessionStorage 的 `kaikou:view`，只在同一個瀏覽器分頁裡保留。沒有 `window.claude` 時改用 localStorage（鍵名 `kaikou:<文件名>`）；連 localStorage 都不能用時只存在記憶體，畫面會提醒。

**網頁版的 AI**：沒有 `window.claude`、網址是 http(s)（`KEY_HERE`，不是直接開檔），而且存了 API 金鑰時，`apiSample()` 取代 `sample()`，介面相同（回傳 `{ text, truncated }`、`onText` 串流、`signal` 停止）。它直接呼叫 Messages API（`stream: true`，標頭 `x-api-key`、`anthropic-version: 2023-06-01`、`anthropic-dangerous-direct-browser-access: true`），把同一方連續的話合併成一則。Claude Haiku 5.5 和 Sonnet 5.5 沒有指定時會先思考（思考的 token 算在 `max_tokens` 和帳單裡，也會讓第一個字晚出現），所以 Haiku 送 `thinking: { type: 'disabled' }`、Sonnet 送 `thinking: { type: 'between_tools' }`（它最低的設定，不先思考），`max_tokens` 分別是 2048 和 8192。錯誤先看 API 的錯誤類型：401 → 金鑰無效，402 或額度不足 → 請儲值，自己設的花費上限（400，「specified API usage limits」）與帳戶等級的每月上限（429，`enforced_spend_limit_reached`）各有說明，403 → 所在地區不支援或金鑰沒有權限，404 → 模型已停用，429 → 用量上限，529 → 太忙；金鑰、額度、上限與模型的問題不提供「重新回覆」（提示或翻譯因為這些問題失敗時，教練還沒回覆的那句也不提供），403 可以換網路後再試。回覆在 `max_tokens` 截斷、JSON 不完整時說明「回覆太長被截斷」。模型名稱和思考的設定都在 `API_MODELS`，換模型時一起看（新的模型可能要不同的 `thinking`）。

- **大小**：平台限制每份文件 256 KiB，程式讓每份都保持在約 160 KiB 以下：每個月的複習最多 150 次，超過大小時先移除該月最舊的；收藏最多 600 句，滿了會請使用者先刪；複習與收藏的各欄位有長度上限。
- **寫入**：每個文件一個佇列、依序寫入。暫時性的失敗（`unavailable`、`resource_exhausted`）會保留變更，以 3 秒起、最長 60 秒的間隔自動重試，右上角顯示「同步失敗，會自動再試」。寫入失敗、正在等重試（或等空出空間）的變更，同時也記在這個瀏覽器（每個分頁一筆 `kaikou:unsent:<帳號>:<分頁>` = `{ at: 最後一次變更的時間, beat: 最後一次更新紀錄的時間, docs, times: 每個欄位改的時間, del: 這個分頁自己刪過、又存回去的項目 }`；每次重試、頁面隱藏或關閉時與每 3 分鐘更新，存好就清掉；記不進去時刪掉舊的那筆，不留過時的內容；頁面在背景時，寫入一失敗就馬上記下，不先等一下再試）。第一次送出的變更不記：頁面關掉時它通常照樣送到，記下來反而可能在之後蓋掉較新的變更；補存的和從「存到雲端」送出的變更則一直記著，直到送到為止。在重試成功前關掉頁面（或手機把背景的分頁收掉），下次在雲端開啟或重新讀取時會自動補存，並提示「已經補存好了」。補存時每個欄位以比較晚的變更為準：紀錄之間、紀錄和這個分頁自己改的（或補存過的，照它原本的時間）都比時間，所以同時開著的另一個分頁改得比較晚，就用它的；先重新讀取雲端上的每份文件，讀的時候這裡又改了的那份會再讀一次，再比一次時間（畫面上不會少了剛改的，也不會被改回去）。雲端在那之後刪掉的收藏、複習排程、隨手記、跟讀短文和對話複習不會被救回；只有那個分頁自己刪掉、後來又收藏的句子會回來（收藏的 id 來自句子本身）。反過來，補存的刪除也不會刪掉在那之後（別台裝置或這裡）又收藏的同一句和它的複習排程。同一天又評了一次的句子用後來的評分。讀不到雲端、讀的時候雲端停止，或這個分頁自己的紀錄記不住時，紀錄就留著下次再送。還開著的分頁的紀錄由它自己送：每個分頁開著時握著以自己紀錄命名的鎖（Web Locks），關掉後鎖才放開；同一個帳號一次只有一個分頁在補存（另一把鎖；不能用鎖時是這個瀏覽器裡一分鐘有效的標記，寫下後稍等再確認還是自己的），兩個分頁同時打開也不會重複送；不能用鎖的瀏覽器，等紀錄 5 分鐘沒更新才代送（還有變更在等的分頁每次重試、每 3 分鐘都會更新）。按「存到雲端」或「再試一次存到雲端」後，變更一記進這個分頁的紀錄，瀏覽器裡留的副本就清掉，下次開啟不會再提醒一次（頁面在存完前關掉，下次照樣補存）。雲端空間已滿或文件太大時不會一直重試，提醒使用者刪東西，刪除後自動再存。已經存在的文件被拒時，算一下加上這次的變更是否真的超過大小限制：沒超過就是沒有寫入權限（例如被改成檢視者：還讀得到自己的資料，但每次寫入都被拒）。沒有寫入權限、權限被收回或資料庫無法使用時，這次改存在這個瀏覽器：每份資料照畫面上的樣子存進去（雲端上一次讀到的版本加上這次的變更；之後重新讀取失敗過的也一樣），取代瀏覽器裡之前留下的那份（舊的那份可能還留著雲端已經刪掉的東西）；這次從沒讀到的資料不寫進去（畫面上那份只是預設值），之後重新讀取時也不會把它清空；沒有權限的非擁有者下次開啟也直接用瀏覽器儲存。下次能用雲端時，今日頁會提醒「這台裝置上有…還沒存到雲端」，按「存到雲端」以合併的方式上傳。在 Claude 裡、但一打開就連不上雲端時（雲端載入失敗，或頁面不是在 Claude 裡打開），也一樣先存在這個瀏覽器並記下變更，畫面會說明；這時畫面上是這個瀏覽器裡的資料（可能是空的、設定是預設值；瀏覽器裡沒有設定的副本時，這次當作讀不到設定，「關於我」先不能改），所以上傳時雲端已經有的那一天保留雲端自己的計畫（也不帶備份檔裡舊格式的 `plan`、`coachMin`），雲端已經收藏的句子保留雲端那一筆，雲端在那之後又複習過的句子保留雲端的排程；這時匯入備份檔也不會匯入設定（設定讀不到時也一樣，合併的訊息會說明；有帶入設定時也會說）。變更是一筆一筆記下的（雲端在資料送出途中停止時，那次沒送到的也一樣記下；之後又改過的，以之後的為準）：這段時間裡新增又刪掉的收藏、隨手記，打勾又取消的項目，就當作沒發生，不會上傳成刪除或取消（畫面上看不到雲端已有的資料時，這種「取消」可能會刪掉你沒看過的東西）；全部都取消了，就沒有東西要上傳。上傳時會先重新讀取雲端上的每份文件，把變更合併在雲端現在的版本上（之前讀不到的月份不會被當成只有這些變更）。上傳的是按下時記著的變更（不是頁面打開時看到的那些）；上傳途中另一個還連不上雲端的分頁又留下的變更（或又改了同一個欄位）繼續留著，提醒會再出現，可以再上傳一次。全部上傳或捨棄之後，瀏覽器裡的副本才清掉（對話除外）；還在用這個瀏覽器儲存的分頁，畫面不會因為副本被清掉而變空，之後的變更照樣記下。一個分頁按了「清除這個瀏覽器裡的練習資料」，其他也在用瀏覽器儲存的分頁會一起重新開始，不會把畫面上的資料再寫回去。記下的變更屬於當時的帳號；Claude 沒說是誰在看時，算在這個瀏覽器上次用雲端的帳號，之後的變更都加進同一份紀錄，不會蓋掉前一次留下的。沒有權限的檢視者按「再試一次存到雲端」時讀不到雲端，就先不搬，按鈕留著（讀的時候改的也記下，下次一起上傳）。這個瀏覽器記著另一個帳號的變更時，按「再試一次存到雲端」不會把那些資料存進自己的雲端，也不會刪掉它們（瀏覽器裡的副本是共用的，這時檢視者自己只存在瀏覽器的變更不會上傳）；頁面會重新從雲端開始，畫面上那個帳號的資料（進行中的對話、複習）之後不會被寫進自己的雲端（重新開啟後如果連不上雲端，就照實說明，不說已改用雲端）。網頁版的瀏覽器儲存空間滿了時，會說明並保留還沒存進去的變更，刪掉一些收藏、隨手記或跟讀短文、刪除存好之後自動再存。
- **讀不到的時候**：某份資料（收藏、某個月的紀錄、設定）讀取失敗或還在讀時，不會把它當成空的去改（設定還沒讀到過時，「關於我」先不能改，打開設定會重新讀取，讀到之後就算游標在框裡也會顯示；讀到過之後，某次重新讀取失敗不影響；還沒讀到過雲端就停止時，這次都不能改，除非之後「再試一次存到雲端」成功、重新讀到）：收藏、打勾、改計畫和每月錄音先等它重新讀取，讀到之後照實際的資料完成（已經收藏的句子就說已在收藏裡）；取消收藏、取消打勾留給你看到實際的資料後自己再按；還是讀不到就說明；連按幾次計畫時，以最後一次為準。做完複習的自動打勾照樣打勾，這時這台裝置的預設計畫寫在比預設值低的權重：雲端那天有自己的計畫就保留，沒有才用這個。設定還讀不到時新的一天也一樣（這時不知道你選的計畫），讀到設定後馬上改成你的預設計畫；別的裝置之後改到那一天時也會補上。
- **重新讀取**：切回頁面、視窗取得焦點（15 秒內不重複）與畫面開著時每 3 分鐘一次；內容沒變就不重畫（這台裝置自己改過的文件不算沒變，所以別台裝置把它改回原樣也會顯示），正在用注音或拼音輸入時等輸入完再重畫（教練的重點或短文晚到、確認按鈕時間到恢復原狀，這些不是你按的重畫也一樣）。讀取期間本機有寫入就丟棄這次結果、下次再讀；從沒載入成功的月份則和本機的變更合併。瀏覽器模式下，同一個瀏覽器的其他分頁存檔時會立刻反映，寫入時也會合併其他分頁的變更。
- **AI 教練**：`sample()` 串流回覆，只在使用者按下按鈕時呼叫。教練的格式是「英文回覆、`###`、每行一個 JSON 更正」，解析時容忍程式碼區塊、`##`、彎引號與被截斷的 JSON（截斷的部分不會顯示）。提示與複習用 `sample()` 取得 JSON 文字再解析，並關閉快取，讓「再試一次」真的重新產生。被拒絕的句子不會再送出，也不算在句數裡；被拒絕或沒有回應時依情況說明（一句話、開場、提示和複習等要求各有不同的說法）。對話中在設定改教練程度，這次對話接下來就照新的程度。
- **無障礙**：重繪時保留鍵盤焦點（`data-fk`）、`#sr-live` 朗讀狀態、分頁可用方向鍵切換、對話泡泡標示語言。按了就不見或變成不能按的按鈕（下個月回到本月、回到今天、寫短文時取消、換主題再練）會把焦點交給接下來的地方；手機上收起或點選提示不會把焦點放進輸入框。語音對話時教練的回覆只用聲音唸，不再送進 `#sr-live`（螢幕閱讀器重唸一次會被麥克風聽到）；等教練回覆時麥克風鍵用 `aria-disabled` 而不是 `disabled`，鍵盤焦點留在原地；麥克風鍵或「唸一次」因為被拒而收起來時，焦點移到輸入框（或分頁按鈕）；按下的按鈕因為畫面改變而不見時（重新回覆、結束並複習、回到練習選單、放棄、刪除、移除金鑰、關閉設定…），焦點移到接下來要用的地方，不會掉到頁面最上面；在手機上這時不會把焦點放進輸入框（以免叫出鍵盤蓋住畫面），而是放在送出鍵（教練回覆時是停止鍵）；開始對話、收起輸入提示也一樣。要按兩次確認的按鈕（放棄、刪除、清除資料、捨棄…），按第一下後 0.6 秒內的第二下不算確認（連點兩下或手指連碰兩下時，第二下會落在換好的按鈕上）；原地切換的按鈕（暫停／繼續、播放、唸一次、收藏、打勾）連點兩下只算一下。設定開著時，提示訊息顯示在設定上面，也照樣朗讀（設定是對話框，外面的東西暫時看不到也讀不到）。教練寫好的短文在你切到別的分頁後才到，不會把那一頁捲到最上面。點輸入提示時，輸入框裡如果是你自己寫的句子，第一下先提醒、再點一次才換掉。更自然的說法和中翻英說法旁的按鈕、「唸一次」的結果標成中文（泡泡本身是英文）。跟讀播放時只更新目前句子的標示，不重畫整頁（拖曳語速、螢幕閱讀器的位置都不會被打斷）。
- **語音**：語音辨識一次只跑一個（`micStart`／`micStop`），用 `continuous: false`，停下來就結束；開始前會先停掉朗讀與跟讀播放。辨識自己結束時，還沒確定的字也算聽到的（有些辨識器不會確定最後一段，部分 Safari 版本從來不確定）。「唸一次」的比對不分大小寫與標點，縮寫（I'm = I am）、okay 和 ok、數字寫法（two = 2、twenty-five = 25、two hundred and fifty = 250、two thousand twenty six = 2026）不同也算對；結果顯示的是句子裡的字數。在 Claude 裡、iPhone 主畫面版不提供麥克風；瀏覽器拒絕時記在 `kaikou:mic-off`（30 天），連不上服務只關掉這一次。4/3/2 用 `MediaRecorder` 錄音（只留在記憶體），兩次之間會放開麥克風；每段錄音一直用同一個播放器，背景重新讀取、重畫時不會中斷正在播的錄音；麥克風中途斷掉時，錄到的部分照樣留著；開始時瀏覽器還在問麥克風、你已經切到別的分頁，這一次會先暫停；計時中用 Wake Lock 讓螢幕不關，切走或鎖定會自動暫停。
- **語音對話**：`Voice.phase` 在 waiting（等教練回覆）→ speaking（`speakThen` 一句一句唸，每句用 `sayOne`，跟讀播放也用它：Chrome 有時會停在很長的一句、也收不到結束通知，所以每句除了結束事件，也看 `speechSynthesis.speaking` 有沒有停下來，另有約 1.3 倍預估長度加 1.5 秒的備用計時器；被打斷之後不會再接著唸下一句）→ listening → countdown（`VOICE_SEND_MS`，期間用另一次辨識繼續聽，聽到聲音就回到 listening 並接在後面）→ waiting 之間循環，另有 paused。每次開始聽、唸、倒數或暫停都換一個 `Voice.tok`，晚到的回呼（被中止的辨識、被打斷的朗讀）不會作用；被打斷的那次聽寫只留下已確定的字（`Voice.drop`）。`ask()` 一開始進入 waiting，`finishTurn` 只在 waiting 時接著唸；暫停時到的回覆記在 `Voice.owed`，按「繼續說」時先唸再聽（已經用喇叭聽過就不再唸）（等回覆時按喇叭或「唸一次」會先暫停，回覆到了不會打斷）。語音條上每個階段的主要按鈕在同一個位置，麥克風鍵也會原地換成下一步，所以連按兩下時第二下不算；麥克風鍵照按下時的意思做（教練說話時按下的「換我說」，放開時麥克風剛好自己打開，仍然是換我說，不會變成「說完了」）。倒數時的辨識被一個雜音打斷、卻沒有聽到字時，倒數重新開始，不算一次沒聲音。沒有手勢自動開始的辨識（`micStart` 的 `auto`）被瀏覽器拒絕時只暫停、不記進 `kaikou:mic-off`；按了「繼續說」還被拒才算真的不允許。在 Claude 裡、中翻英、沒有朗讀或麥克風被關掉時不提供。
- **發音練習**：課程內容在 `PRON`（8 組，每組 6 對字、3 句；字對避開 live、read 這種朗讀可能唸成兩種音的字），其他拼法在 `PRON_ALTS`。`pronVerdict` 比對辨識結果：聽到這個字（或同音拼法）、聽到另一個字、或都不是；只有前兩種記進成績。

共 160 項檢查，全部通過時最後印出「全部 160 項檢查通過」，截圖存到 `test/shots/`。只跑其中幾段：`npm test -- 3b,6`（每種命令列都能用；也可以用環境變數 `ONLY=3b,6 npm test`。段落編號見 `test/run.js` 每段的標題；寫錯編號會直接報錯，一項都沒跑也算失敗）。需要 Node.js 20 以上。

發布腳本（Mac 版 `推送到GitHub.command`）另有測試：`bash test/publish.sh`（Mac 或 Linux，需要 Git；Windows 可以在 Git Bash 裡跑）。它用本機的假 GitHub 照著各種情況跑一遍：沒有變更、發布、取消、GitHub 上有新版、衝突、別的方式做的 commit、第一次設定名字和 email（按 Y 再按 Enter）、沒有 Git、推送被拒或要登入、還沒完成的 rebase／merge／cherry-pick／revert、從暫存拿回變更時留下的衝突、檔案或 commit 裡留著衝突標記。Windows 版做同樣的檢查，但這裡沒辦法執行它。

## 更新與發布

1. 修改 `docs/index.html`（VS Code、Claude Code 都可以）
2. 點 `推送到GitHub.bat`（Windows）或 `推送到GitHub.command`（Mac，會在「終端機」裡執行）：列出這次要發布的變更並詢問（Windows 版按 Y 發布、N 取消；Mac 版輸入 Y 或 N 再按 Enter），同步 GitHub 上的版本後推送；GitHub Pages 約 1 分鐘後更新。只會發布 `docs/`、`test/`、`tools/` 與 repo 裡原有的檔案，資料夾裡其他新檔案（`??` 開頭的）不會上傳。這台電腦上用別的方式（例如 VS Code）做過、還沒上 GitHub 的 commit，會先列出它們和改到的檔案，按 Y 才一起發布，按 N 就留在這台電腦；這次的變更如果 GitHub 上已經有了（同步時會略過），也不會把別的 commit 當成這次的直接推上去，一樣先列出來問你。和 GitHub 上的版本衝突時會停下來，不會發布，也不會動到你的檔案；如果有其他程式正在用 Git、沒辦法自動復原，會說明要怎麼做。之前的合併、rebase、cherry-pick 或 revert 還沒完成，或是有檔案的衝突還沒解決（例如 VS Code 同步時把你的變更拿回來而衝突）、要發布的檔案或 commit 裡還留著 `<<<<<<<` 這類的衝突標記時，也會停下來，不會發布（發布出去的話，網站上的程式會壞掉）。
3. 完整版：把改好的檔案交給 Claude，轉成頁面片段後重新發佈到同一個 Artifact 連結

**第一次在 Mac 上發布**

- 還沒有 Git 時，Mac 會跳出安裝「命令列開發者工具」的視窗，按「安裝」，裝好後再點一次。
- Mac 說無法打開這個檔案（Apple 無法確認它沒有惡意軟體、或來自未識別的開發者）時：先按「完成」，到「系統設定」→「隱私權與安全性」，往下找到這個檔案被阻擋的說明，按旁邊的「強制打開」，再點一次這個檔案（macOS 15 以後在檔案上按右鍵 →「打開」已經不能略過這個檢查；macOS 14 以前也可以那樣做）。用 `git clone` 拿到的資料夾通常不會被擋，從網路下載或 AirDrop 收到的才會。終端機問能不能取用「桌面」的檔案時，按「好」。
- 會問一次 commit 上顯示的名字和 email（公開在 GitHub 上，可以用 GitHub 的 noreply 地址），只存在這個資料夾的設定裡。
- 推送時 GitHub 會問帳號和密碼：密碼要貼 GitHub 的 Personal access token，不是登入密碼（github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens，Repository access 選 `kaikou-practice`，Contents 選 Read and write）。Mac 會把它存進鑰匙圈，到期前不用再輸入；需要輸入時，腳本會先說明。
