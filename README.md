# 開口練習室

英文口說練習的網頁 App：每日練習菜單與打卡、AI 對話教練、練習紀錄與收藏。整個程式就是 `docs/index.html` 一個檔案（HTML、CSS、JavaScript 寫在一起），不需要建置，部署在 GitHub Pages。

| 分頁 | 內容 |
| --- | --- |
| 今日 | 20／60 分鐘菜單打勾（影子跟讀、AI 對話、語塊複習、聽 Podcast）；每週真人家教與 4/3/2 錄音；每月進度錄音；「說不出口的句子」隨手記，之後可以交給教練 |
| 教練 | 自由聊天、情境角色扮演、中翻英口說。每句話下面附更自然的說法，可以朗讀、看中文、要提示；按「結束並複習」產生這次的摘要、要注意的地方與值得收藏的說法，並自動打勾、記錄分鐘數 |
| 紀錄 | 月曆蓋章、練習天數、達標天數、專注分鐘、連續天數，以及每次複習的摘要 |
| 收藏 | 開口救急包 12 句、收藏的說法；可以複製成 Anki 匯入格式 |

## 兩種開法

| | 在 Claude 裡開啟（完整版） | GitHub Pages 或直接開檔案 |
| --- | --- | --- |
| AI 教練 | 可以用（用自己的 Claude 帳號，第一次使用會詢問是否允許） | 不能用 |
| 資料存放 | Claude 雲端，只有自己看得到，手機和電腦會同步 | 這個瀏覽器的 localStorage，不會同步；設定裡可以清除 |
| 今日、紀錄、收藏 | 可以用 | 可以用 |

- GitHub Pages：<https://willisxu.github.io/kaikou-practice/>
- 完整版是發佈在 Claude 的 Artifact，連結記在本機的 `使用說明.txt`（只在自己電腦上，不進版控）。
- 別人用分享連結開啟、但沒有寫入權限時，頁面會改存在他自己的瀏覽器，並在畫面上說明；之後拿到權限，可以在設定按「再試一次存到雲端」把資料搬上去。

頁面本身不收音，用系統的語音輸入練「說」：Windows 按 <kbd>Win</kbd> + <kbd>H</kbd>；手機把鍵盤切到英文、點麥克風。先大聲說，再送出。

## 程式重點（給維護的人）

**一個檔案、兩個地方用**：`docs/index.html` 是完整的 HTML 文件，GitHub Pages 和直接開檔都用它。Claude 的 Artifact 會自己包上 `<!doctype>`、`<html>`、`<head>`、`<body>`，所以發佈到 Claude 時要用 `tools/artifact.js` 轉成頁面片段（`npm run artifact -- 輸出檔`），拿掉這幾層外框，其餘內容不變。

**平台介面**：在 Claude 裡用 `window.claude.use('db' | 'sample' | 'user')` 取得資料庫、AI 與使用者 id；`window.claude.hot` 用來在頁面更新時保留目前的分頁與草稿。沒有 `window.claude` 時改用 localStorage（鍵名 `kaikou:<文件名>`）；連 localStorage 都不能用時只存在記憶體，畫面會提醒。

**資料**（每位使用者自己的 `data/users/<id>/` 底下）

| 文件 | 內容 | 寫法 |
| --- | --- | --- |
| `settings` | 練習量、程度、自我介紹、口音、語速、自動朗讀 | 只更新改到的欄位 |
| `log-YYYY-MM` | `days[日期] = { plans, items, coach }`、`monthRecord` | 只送出改到的項目。`plans` 以「權重 → 方案」存：建立當天的裝置寫預設值（權重 0），手動選擇寫在時間戳記下，權重最高的生效，所以還沒更新的裝置不會蓋掉另一台的選擇。`coach` 以對話 id 記分鐘，重送不會重複累加 |
| `phrases`、`inbox`、`sessions-YYYY-MM` | 以 id 為鍵的 map | 用 `update` 合併，刪除寫 `null`，兩台裝置各自新增不會互相覆蓋。舊版的 `items` 陣列仍讀得到 |
| `chat` | 進行中的對話（最近 60 句，太長時再少一些） | 整份寫入；複習存好之後才標記結束，而且只在雲端存的還是同一個對話時才標記 |

- **大小**：平台限制每份文件 256 KiB，程式讓每份都保持在約 160 KiB 以下：每個月的複習最多 150 次，超過大小時先移除該月最舊的；收藏最多 600 句，滿了會請使用者先刪；複習與收藏的各欄位有長度上限。
- **寫入**：每個文件一個佇列、依序寫入。暫時性的失敗（`unavailable`、`resource_exhausted`）會保留變更，以 3 秒起、最長 60 秒的間隔自動重試，右上角顯示「同步失敗，會自動再試」。雲端空間已滿或文件太大時不會一直重試，提醒使用者刪東西，刪除後自動再存。沒有寫入權限（小文件被拒）、權限被收回或資料庫無法使用時，這次改存在這個瀏覽器（和瀏覽器裡已有的資料合併，不會蓋掉）；沒有權限的非擁有者下次開啟也直接用瀏覽器儲存。下次能用雲端時，今日頁會提醒「這台裝置上有…還沒存到雲端」，按「存到雲端」以合併的方式上傳。
- **重新讀取**：切回頁面、視窗取得焦點（15 秒內不重複）與畫面開著時每 3 分鐘一次；內容沒變就不重畫，正在用注音或拼音輸入時等輸入完再重畫。讀取期間本機有寫入就丟棄這次結果、下次再讀；從沒載入成功的月份則和本機的變更合併。瀏覽器模式下，同一個瀏覽器的其他分頁存檔時會立刻反映，寫入時也會合併其他分頁的變更。
- **AI 教練**：`sample()` 串流回覆，只在使用者按下按鈕時呼叫。教練的格式是「英文回覆、`###`、每行一個 JSON 更正」，解析時容忍程式碼區塊、`##`、彎引號與被截斷的 JSON（截斷的部分不會顯示）。提示與複習用 `sample()` 取得 JSON 文字再解析，並關閉快取，讓「再試一次」真的重新產生。被拒絕的句子不會再送出，也不算在句數裡。
- **無障礙**：重繪時保留鍵盤焦點（`data-fk`）、`#sr-live` 朗讀狀態、分頁可用方向鍵切換、對話泡泡標示語言。

## 測試

`test/run.js` 是 Playwright 瀏覽器測試，任何一項檢查失敗都會以非 0 結束碼結束：

- 在 Claude 裡（`test/mock.js` 模擬 `window.claude`，包含資料庫的合併規則與大小限制）：打卡蓋章、對話與更正、提示、翻譯、結束並複習、紀錄、收藏、問教練、放棄對話、設定。
- GitHub Pages：直接打開 `docs/index.html`，用手機模擬，確認一次只顯示一個分頁、沒有左右捲動，同一個瀏覽器開兩個分頁不會互相蓋掉。
- 失敗情況：寫入失敗後自動重試、沒有寫入權限時改存瀏覽器（以及之後再存回雲端）、同步中途停止後下次上傳、被拒絕的句子、停止回覆、雲端空間已滿。

```
npm install
npx playwright install chromium
npm test
```

全部通過時最後印出「全部檢查通過」，截圖存到 `test/shots/`。需要 Node.js 20 以上。

## 更新與發布

1. 修改 `docs/index.html`（VS Code、Claude Code 都可以）
2. 點 `推送到GitHub.bat`：列出這次要發布的變更並詢問（按 Y 發布、N 取消），同步 GitHub 上的版本後推送；GitHub Pages 約 1 分鐘後更新。只會發布 `docs/`、`test/`、`tools/` 與 repo 裡原有的檔案，資料夾裡其他新檔案（`??` 開頭的）不會上傳。和 GitHub 上的版本衝突時會停下來，不會發布，也不會動到你的檔案。
3. 完整版：把改好的檔案交給 Claude，轉成頁面片段後重新發佈到同一個 Artifact 連結

需求：Git（推送用）；跑測試另需 Node.js 20 以上。
