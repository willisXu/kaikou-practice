# 開口練習室

英文口說練習的網頁 App：每日練習菜單與打卡、AI 對話教練（網頁版可以用語音對話）、句子間隔複習、發音重點練習、影子跟讀、4/3/2 計時、練習紀錄與收藏。整個程式就是 `docs/index.html` 一個檔案（HTML、CSS、JavaScript 寫在一起），不需要建置，部署在 GitHub Pages。

| 分頁 | 內容 |
| --- | --- |
| 今日 | 20／60 分鐘菜單打勾（影子跟讀、AI 對話、語塊複習、聽 Podcast）；每週真人家教與 4/3/2；每月進度錄音；「說不出口的句子」隨手記，之後可以交給教練。影子跟讀和 4/3/2 可以直接在這裡練（見下方） |
| 教練 | 自由聊天、情境角色扮演、中翻英口說。每句話下面附更自然的說法，可以朗讀、唸一次檢查、看中文、要提示；網頁版可以開「語音對話」，像講電話一樣不用碰螢幕。按「結束並複習」產生這次的摘要、要注意的地方與值得收藏的說法，並自動打勾、記錄分鐘數 |
| 紀錄 | 月曆蓋章、練習天數、達標天數、專注分鐘、連續天數，以及每次複習的摘要 |
| 收藏 | 每日句子複習（間隔重複）、發音重點練習 8 組、開口救急包 12 句、收藏的說法；可以複製成 Anki 匯入格式 |

### 練習工具

- **句子複習**（收藏分頁，今日的「語塊複習」也會帶過去）：看提示先大聲說英文，再翻面對答案，按「忘了／有點卡／記得」。提示是收藏時的中文；從「更自然的說法」收藏的句子，會給你原本的說法，請你說出更好的版本。新句子「記得」2 天後再出現、「有點卡」1 天，之後每次「記得」間隔約變成 2.5 倍（「有點卡」1.2 倍），「忘了」這一輪會再出現一次。每天最多加入 10 句新句子，一輪最多 20 句。一輪做完自動打勾「語塊複習」。電腦上可以用空白鍵翻面、1／2／3 評分。
- **影子跟讀**（今日 → 影子跟讀 →「在這裡跟讀」）：請教練依你的程度寫 6 或 10 句的短文，或貼上自己的英文逐字稿（最多 30 句）。可以「聽一句、跟一句」（每句後面留出跟讀的時間）或連續播放，可調語速（0.5–1.2 倍）、隱藏稿子、看中文。按「完成今天的跟讀」會打勾並記下這篇練了幾天，同一篇建議練 3–5 天。最近 12 篇會留著。
- **4/3/2**（今日 → 4/3/2 →「開始 4/3/2」）：同一個主題講 4、3、2 分鐘，計時可暫停，時間到會響（手機會震動），三次講完自動打勾本週的 4/3/2。可以請教練給 3 個重點和用得上的說法。網頁版可以每次都錄音，三次講完一起聽、下載（錄音不會存起來）。計時中切到別的分頁或手機鎖定會自動暫停；瀏覽器支援時，計時中螢幕會保持開著。
- **語音對話**（只有網頁版，自由聊天與情境角色扮演）：在教練選單按「開始語音對話」，或對話中按「語音對話」。教練的回覆會唸出來，唸完自動開麥克風聽你說；你說完停一下，輸入框裡的文字倒數 2.5 秒就自動送出。倒數時麥克風還在聽，說到一半停頓、接著說下去，會接在後面一起送，不會只送半句。倒數時可以按「先不要送」（文字留在輸入框，可以改）或「現在送出」，按輸入框旁的麥克風表示還沒說完。打字、點輸入框、看提示、按喇叭或「唸一次」、打開設定、換分頁、鎖定手機都會先暫停，按「繼續說」接下去（暫停時教練的回覆到了，按「繼續說」會先唸出來再聽你說；教練正在說時打字，會等教練說完才停；說到一半被別的事打斷，還沒確定的字不會留下，再說一次不會重複；點輸入框則留下畫面上的字讓你改）；提示放進輸入框後直接唸出來，會換成你唸的版本。一直沒說話時會再聽兩次（給你想的時間），還是沒聲音就暫停。語音對話一定會唸教練的回覆，所以這時「自動朗讀」按鈕先收起來。按「放棄」「結束並複習」或語音條上的 × 結束。
- **發音重點練習**（收藏分頁）：說中文的人常混在一起的 8 組音：th（think／sink）、v（very／wery）、字尾子音（bag／back）、長短 i（sheep／ship）、æ 和 e（bad／bed）、s 和 sh（see／she）、n 和 ng（win／wing）、r 和 l（right／light）。每組有發音方法、6 對字、6 題的聽辨小測驗（播一個字，選你聽到哪一個）和 3 句練習句。網頁版可以對著麥克風唸一個字，看電腦聽到的是這個字、另一個字，還是聽不出來（同音的拼法也算對，例如 sea／see）；電腦常會往常見的字猜，結果當參考。每組的成績（最近 20 次唸字、上次聽辨）只存在這個瀏覽器（`kaikou:pron`），不會同步，也不在備份檔裡。
- **麥克風**（只有網頁版）：教練的輸入框旁有麥克風鍵，說完會自動停，文字進輸入框，確認後再送出。中翻英練習先聽中文，教練給說法之後自動改聽英文（輸入框旁的「中／EN」可以切換）。每句「更自然的說法」、收藏、複習卡和跟讀句子旁都有「唸一次」：唸給它聽，沒聽出來的字會用紅色波浪線標出。詳見下方「麥克風」。

## 麥克風（網頁版）

- 用的是瀏覽器內建的語音辨識：Chrome 和 Edge 會把聲音送到它們的服務（Chrome 是 Google），Safari 用 Apple 的聽寫。第一次用時瀏覽器會問是否允許麥克風。
- **連不上服務時**（例如在中國大陸用 Chrome、沒有連 VPN）：會顯示說明，這次先把麥克風關掉，改用系統的語音輸入；網路正常後到設定按「重新啟用麥克風」。
- **瀏覽器不允許時**：說明怎麼在網站設定允許，麥克風鍵會收起來，之後打開也會記得（30 天）；允許之後到設定按「重新啟用麥克風」。
- **iPhone**：要在 Safari 裡用，並開啟 Siri 與聽寫。從主畫面打開的版本，iPhone 不提供語音辨識，所以不會出現麥克風鍵。
- 播放跟讀或朗讀時一按麥克風，播放會先停，免得錄到自己的喇叭聲。語音對話也是等教練唸完才開麥克風。
- **語音對話在 iPhone 上**：有些瀏覽器要按一下才肯開始聽。教練唸完後如果停在「瀏覽器要你先按一下」，按「繼續說」就好，之後每一輪可能都要按一次。
- **在中國大陸**：Chrome 的語音辨識用 Google 的服務，沒有 VPN 時連不上，語音對話會關掉並說明。可以試試 iPhone 或 Mac 的 Safari（用 Apple 的聽寫）。

## 朗讀的聲音

Claude 版和網頁版都一樣：設定的「聲音」選「自動選擇」時，先用這台裝置上的聲音（有你選的口音就用那個口音，沒有就用裝置上其他的英文聲音），要唸的文字不會離開裝置。清單裡標「線上」的聲音（例如 Edge 的 Microsoft … Online、Chrome 的 Google 聲音）比較自然，但要唸的文字（教練的回覆、收藏的句子、跟讀短文）會送到 Microsoft 或 Google 的服務，在中國大陸可能連不上；裝置上沒有英文聲音時，自動選擇也只能用線上的。

## 備份與搬移

設定 →「匯出備份檔」存成 `kaikou-backup-日期.json`，內容是設定、打卡、收藏、隨手記、句子複習排程、對話複習（教練整理的摘要，含你在對話裡說過的句子）和跟讀短文（不含進行中的對話，也不含 API 金鑰）。在另一台裝置或另一個版本按「匯入備份檔」，會先列出檔案裡有什麼，按「合併到這裡」才合併：

- 只會新增，不會刪掉任何東西；同一天兩邊的打勾都保留；同一句的複習排程取最後複習的那一邊；設定只在這裡還是預設值時才匯入（不然只補上空白的「關於我」；在 Claude 裡但連不上雲端、畫面上是這個瀏覽器的資料時，不匯入設定）。
- 收藏、隨手記、跟讀短文已經滿了，放不下的就不加，並在提示裡說明。
- 重複匯入同一個檔案不會多出東西。這裡有資料還讀不到（雲端暫時連不上）時會先不合併，檔案留著，等一下再按一次。
- 日期要是真的日期（2020 年起、不晚於明天），而且放在自己的月份裡；其他的略過，不會多出奇怪的月份。
- 在 Claude 裡匯出時，會先請你確認下載；匯出的是雲端上每個月的資料（以雲端存的版本為準，這台裝置還沒存好的變更再合併上去）。

## 加到主畫面（GitHub Pages）

設定裡的「加到主畫面」有說明：Android 和電腦上的 Chrome、Edge 有「安裝到主畫面」按鈕；iPhone 用 Safari 的「分享」→「加入主畫面」。裝好之後像 App 一樣從圖示打開，沒有網路也能打開頁面（`docs/sw.js`：頁面先向網路拿最新版並存一份；沒有網路、伺服器出錯或 4 秒內沒有回應，就用上次存的那份。網站搬家（轉址）時照網路的回應走，不會一直停在舊的頁面）。直接打開檔案時沒有這個功能。iPhone 從主畫面打開時，資料可能和 Safari 分開存放，請用備份檔搬過去，API 金鑰也要重新輸入。

## 在網頁版用 AI 教練（自己的 Claude API 金鑰）

1. 到 [Claude Console](https://platform.claude.com) 登入，先在 Settings → Billing 儲值，再到 Settings → API keys 按 Create key。金鑰只會顯示一次，開頭是 `sk-ant-api`。
2. 打開 GitHub Pages 網址，按右上角的設定，在「Claude API 金鑰」貼上、按「儲存」。
3. 回到「教練」分頁開始對話。

- **費用**：對話、提示、翻譯和 4/3/2 的重點用 Claude Haiku 5.5（`claude-haiku-5-5`），「結束並複習」和跟讀短文用 Claude Sonnet 5.5（`claude-sonnet-5-5`），依實際用量計費。可以在 Claude Console 設定花費上限。
- **安全**：金鑰只存在這個瀏覽器（localStorage 的 `kaikou:api-key`），只送到 `api.anthropic.com`，不會存進雲端資料或 git。畫面上只顯示最後 4 碼。金鑰在瀏覽器裡，就可能被這個網域的其他頁面讀到：`willisxu.github.io` 底下的其他 GitHub Pages 專案和這個頁面共用同一份 localStorage。所以只在自己的裝置存，公用電腦不要存。
- **只能在網址上用**：直接打開 `docs/index.html` 檔案時不能存金鑰（這台電腦上直接打開的網頁檔案共用同一份 localStorage，任何一個都讀得到它），所以那時沒有 AI 教練。以前在直接開檔時存過的金鑰，打開頁面時會自動移除，今日頁會提醒你到 Console 停用那把金鑰、再建一把新的。
- **外流時**：到 Console 的 API keys 停用或刪除那把金鑰，再建一把新的。
- 「清除這個瀏覽器裡的練習資料」不會刪掉金鑰（也不會刪掉金鑰已移除的提醒）；要刪金鑰，按設定裡的「移除金鑰」。
- 在 Claude 裡開啟時不需要金鑰，設定裡也不會出現這個欄位（Claude 裡的頁面不能連到外部網站）。

## 程式重點（給維護的人）

**一個檔案、兩個地方用**：`docs/index.html` 是完整的 HTML 文件，GitHub Pages 和直接開檔都用它。Claude 的 Artifact 會自己包上 `<!doctype>`、`<html>`、`<head>`、`<body>`，所以發佈到 Claude 時要用 `tools/artifact.js` 轉成頁面片段（`npm run artifact -- 輸出檔`），拿掉這幾層外框，也拿掉只給 GitHub Pages 用、標了 `data-pages-only` 的標籤（manifest、主畫面圖示、theme-color），其餘內容不變。主畫面圖示用 `node tools/make-icons.js` 產生（需要 Noto Serif CJK TC 字型）。

**字型不擋畫面**：Google Fonts 的樣式表先以 `media="print"` 載入，到了才在程式裡換成 `all`，所以字型服務很慢或連不上時（例如在中國大陸），頁面照常用系統字型打開。

**平台介面**：在 Claude 裡用 `window.claude.use('db' | 'sample' | 'user' | 'downloads')` 取得資料庫、AI、使用者 id 與下載（匯出備份檔）；重新整理（包括頁面更新後重新載入）時，目前的分頁和還沒送出的文字存在 sessionStorage 的 `kaikou:view`，只在同一個瀏覽器分頁裡保留。沒有 `window.claude` 時改用 localStorage（鍵名 `kaikou:<文件名>`）；連 localStorage 都不能用時只存在記憶體，畫面會提醒。

**網頁版的 AI**：沒有 `window.claude`、網址是 http(s)（`KEY_HERE`，不是直接開檔），而且存了 API 金鑰時，`apiSample()` 取代 `sample()`，介面相同（回傳 `{ text, truncated }`、`onText` 串流、`signal` 停止）。它直接呼叫 Messages API（`stream: true`，標頭 `x-api-key`、`anthropic-version: 2023-06-01`、`anthropic-dangerous-direct-browser-access: true`），把同一方連續的話合併成一則。錯誤對應：401／403 → 金鑰無效，額度不足 → 請儲值，404 → 模型已停用，429 → 用量上限，529 → 太忙，這些都會顯示中文說明；金鑰、額度與模型的問題不提供「重新回覆」。模型名稱在 `API_MODELS`，模型停用時改這裡。

**資料**（每位使用者自己的 `data/users/<id>/` 底下）

| 文件 | 內容 | 寫法 |
| --- | --- | --- |
| `settings` | 練習量、程度、自我介紹、口音、語速、自動朗讀 | 只更新改到的欄位 |
| `log-YYYY-MM` | `days[日期] = { plans, items, coach }`、`monthRecord` | 只送出改到的項目。`plans` 以「權重 → 方案」存：建立當天的裝置寫預設值（權重 0；還讀不到那個月時建立的寫在 -1，只在沒有別的預設或選擇時生效），手動選擇寫在時間戳記下，權重最高的生效，所以還沒更新的裝置不會蓋掉另一台的選擇。`coach` 以對話 id 記分鐘，重送不會重複累加 |
| `phrases`、`inbox`、`sessions-YYYY-MM` | 以 id 為鍵的 map | 用 `update` 合併，刪除寫 `null`，兩台裝置各自新增不會互相覆蓋。舊版的 `items` 陣列仍讀得到。收藏的「更自然的說法」多存一個 `was`（原本的說法） |
| `srs` | `map[收藏 id] = { d: 下次日期, i: 間隔天數, r: 連續記得次數, l: 忘記次數, f: 第一次複習, t: 最後複習, pt: 這次評分根據的前一次複習 }` | 每評一張卡寫那一筆；刪除收藏時寫 `null`。排程比收藏的時間還舊（同一句刪掉後又收藏）就當新句子。還讀不到 `srs` 時不開始複習，以免蓋掉排好的時間；暫時存在瀏覽器、之後上傳的排程，只在接續雲端同一份排程（第一次複習同一天），而且雲端在 `pt` 之後沒有再複習過時才送出（瀏覽器的副本可能比雲端舊或是空的）；舊版留下、沒有 `pt` 的，接續同一份排程而且不比雲端舊時才送；其他情況都保留雲端的排程 |
| `shadow` | `{ cur, map[id] = { title, level, at, src, sents: [{ en, zh }], days } }` | 最多 12 篇、約 120 KiB，新增時移除最舊的；`days` 記練過的日期 |
| `chat` | 進行中的對話（最近 60 句，太長時再少一些） | 整份寫入；複習存好之後才標記結束，而且只在雲端存的還是同一個對話時才標記 |

- **大小**：平台限制每份文件 256 KiB，程式讓每份都保持在約 160 KiB 以下：每個月的複習最多 150 次，超過大小時先移除該月最舊的；收藏最多 600 句，滿了會請使用者先刪；複習與收藏的各欄位有長度上限。
- **寫入**：每個文件一個佇列、依序寫入。暫時性的失敗（`unavailable`、`resource_exhausted`）會保留變更，以 3 秒起、最長 60 秒的間隔自動重試，右上角顯示「同步失敗，會自動再試」。雲端空間已滿或文件太大時不會一直重試，提醒使用者刪東西，刪除後自動再存。沒有寫入權限（小文件被拒）、權限被收回或資料庫無法使用時，這次改存在這個瀏覽器（和瀏覽器裡已有的資料合併，不會蓋掉）；沒有權限的非擁有者下次開啟也直接用瀏覽器儲存。下次能用雲端時，今日頁會提醒「這台裝置上有…還沒存到雲端」，按「存到雲端」以合併的方式上傳。在 Claude 裡、但一打開就連不上雲端時（雲端載入失敗，或頁面不是在 Claude 裡打開），也一樣先存在這個瀏覽器並記下變更，畫面會說明；這時畫面上是這個瀏覽器裡的資料（可能是空的、設定是預設值），所以上傳時雲端已經有的那一天保留雲端自己的計畫（也不帶備份檔裡舊格式的 `plan`、`coachMin`），雲端已經收藏的句子保留雲端那一筆，雲端在那之後又複習過的句子保留雲端的排程；這時匯入備份檔也不會匯入設定。變更是一筆一筆記下的（雲端在資料送出途中停止時，那次沒送到的也一樣記下；之後又改過的，以之後的為準）：這段時間裡新增又刪掉的收藏、隨手記，打勾又取消的項目，就當作沒發生，不會上傳成刪除或取消（畫面上看不到雲端已有的資料時，這種「取消」可能會刪掉你沒看過的東西）；全部都取消了，就沒有東西要上傳。上傳或捨棄之後，瀏覽器裡的副本會清掉（對話除外）。記下的變更屬於當時的帳號；Claude 沒說是誰在看時，算在這個瀏覽器上次用雲端的帳號，之後的變更都加進同一份紀錄，不會蓋掉前一次留下的。網頁版的瀏覽器儲存空間滿了時，會說明並保留還沒存進去的變更，刪掉一些收藏、隨手記或跟讀短文、刪除存好之後自動再存。
- **讀不到的時候**：某份資料（收藏、某個月的紀錄）讀取失敗或還在讀時，不會把它當成空的去改：收藏、打勾、改計畫和每月錄音先等它重新讀取，讀到之後照實際的資料完成（已經收藏的句子就說已在收藏裡）；取消收藏、取消打勾留給你看到實際的資料後自己再按；還是讀不到就說明；連按幾次計畫時，以最後一次為準。做完複習的自動打勾照樣打勾，這時這台裝置的預設計畫寫在比預設值低的權重：雲端那天有自己的計畫就保留，沒有才用這個。
- **重新讀取**：切回頁面、視窗取得焦點（15 秒內不重複）與畫面開著時每 3 分鐘一次；內容沒變就不重畫，正在用注音或拼音輸入時等輸入完再重畫。讀取期間本機有寫入就丟棄這次結果、下次再讀；從沒載入成功的月份則和本機的變更合併。瀏覽器模式下，同一個瀏覽器的其他分頁存檔時會立刻反映，寫入時也會合併其他分頁的變更。
- **AI 教練**：`sample()` 串流回覆，只在使用者按下按鈕時呼叫。教練的格式是「英文回覆、`###`、每行一個 JSON 更正」，解析時容忍程式碼區塊、`##`、彎引號與被截斷的 JSON（截斷的部分不會顯示）。提示與複習用 `sample()` 取得 JSON 文字再解析，並關閉快取，讓「再試一次」真的重新產生。被拒絕的句子不會再送出，也不算在句數裡；被拒絕或沒有回應時依情況說明（一句話、開場、提示和複習等要求各有不同的說法）。對話中在設定改教練程度，這次對話接下來就照新的程度。
- **無障礙**：重繪時保留鍵盤焦點（`data-fk`）、`#sr-live` 朗讀狀態、分頁可用方向鍵切換、對話泡泡標示語言。語音對話時教練的回覆只用聲音唸，不再送進 `#sr-live`（螢幕閱讀器重唸一次會被麥克風聽到）；等教練回覆時麥克風鍵用 `aria-disabled` 而不是 `disabled`，鍵盤焦點留在原地；麥克風鍵或「唸一次」因為被拒而收起來時，焦點移到輸入框（或分頁按鈕）；按下的按鈕因為畫面改變而不見時（重新回覆、結束並複習、回到練習選單、放棄、刪除、移除金鑰、關閉設定…），焦點移到接下來要用的地方，不會掉到頁面最上面；在手機上這時不會把焦點放進輸入框（以免叫出鍵盤蓋住畫面）。更自然的說法和中翻英說法旁的按鈕、「唸一次」的結果標成中文（泡泡本身是英文）。跟讀播放時只更新目前句子的標示，不重畫整頁（拖曳語速、螢幕閱讀器的位置都不會被打斷）。
- **語音**：語音辨識一次只跑一個（`micStart`／`micStop`），用 `continuous: false`，停下來就結束；開始前會先停掉朗讀與跟讀播放。「唸一次」的比對不分大小寫與標點，縮寫（I'm = I am）、okay 和 ok、數字寫法（two = 2、twenty-five = 25、two hundred and fifty = 250、two thousand twenty six = 2026）不同也算對；結果顯示的是句子裡的字數。在 Claude 裡、iPhone 主畫面版不提供麥克風；瀏覽器拒絕時記在 `kaikou:mic-off`（30 天），連不上服務只關掉這一次。4/3/2 用 `MediaRecorder` 錄音（只留在記憶體），兩次之間會放開麥克風；麥克風中途斷掉時，錄到的部分照樣留著；開始時瀏覽器還在問麥克風、你已經切到別的分頁，這一次會先暫停；計時中用 Wake Lock 讓螢幕不關，切走或鎖定會自動暫停。
- **語音對話**：`Voice.phase` 在 waiting（等教練回覆）→ speaking（`speakThen` 一句一句唸，每句用 `sayOne`，跟讀播放也用它：Chrome 有時會停在很長的一句、也收不到結束通知，所以每句除了結束事件，也看 `speechSynthesis.speaking` 有沒有停下來，另有約 1.3 倍預估長度加 1.5 秒的備用計時器；被打斷之後不會再接著唸下一句）→ listening → countdown（`VOICE_SEND_MS`，期間用另一次辨識繼續聽，聽到聲音就回到 listening 並接在後面）→ waiting 之間循環，另有 paused。每次開始聽、唸、倒數或暫停都換一個 `Voice.tok`，晚到的回呼（被中止的辨識、被打斷的朗讀）不會作用；被打斷的那次聽寫只留下已確定的字（`Voice.drop`）。`ask()` 一開始進入 waiting，`finishTurn` 只在 waiting 時接著唸；暫停時到的回覆記在 `Voice.owed`，按「繼續說」時先唸再聽（已經用喇叭聽過就不再唸）（等回覆時按喇叭或「唸一次」會先暫停，回覆到了不會打斷）。語音條上每個階段的主要按鈕在同一個位置，麥克風鍵也會原地換成下一步，所以連按兩下時第二下不算。沒有手勢自動開始的辨識（`micStart` 的 `auto`）被瀏覽器拒絕時只暫停、不記進 `kaikou:mic-off`；按了「繼續說」還被拒才算真的不允許。在 Claude 裡、中翻英、沒有朗讀或麥克風被關掉時不提供。
- **發音練習**：課程內容在 `PRON`（8 組，每組 6 對字、3 句；字對避開 live、read 這種朗讀可能唸成兩種音的字），其他拼法在 `PRON_ALTS`。`pronVerdict` 比對辨識結果：聽到這個字（或同音拼法）、聽到另一個字、或都不是；只有前兩種記進成績。

## 更新與發布

1. 修改 `docs/index.html`（VS Code、Claude Code 都可以）
2. 點 `推送到GitHub.bat`（Windows）或 `推送到GitHub.command`（Mac，會在「終端機」裡執行）：列出這次要發布的變更並詢問（按 Y 發布、N 取消），同步 GitHub 上的版本後推送；GitHub Pages 約 1 分鐘後更新。只會發布 `docs/`、`test/`、`tools/` 與 repo 裡原有的檔案，資料夾裡其他新檔案（`??` 開頭的）不會上傳。這台電腦上用別的方式（例如 VS Code）做過、還沒上 GitHub 的 commit，會先列出它們和改到的檔案，按 Y 才一起發布，按 N 就留在這台電腦；這次的變更如果 GitHub 上已經有了（同步時會略過），也不會把別的 commit 當成這次的直接推上去，一樣先列出來問你。和 GitHub 上的版本衝突時會停下來，不會發布，也不會動到你的檔案；如果有其他程式正在用 Git、沒辦法自動復原，會說明要怎麼做。
3. 完整版：把改好的檔案交給 Claude，轉成頁面片段後重新發佈到同一個 Artifact 連結

**第一次在 Mac 上發布**

- 還沒有 Git 時，Mac 會跳出安裝「命令列開發者工具」的視窗，按「安裝」，裝好後再點一次。
- Mac 說「無法打開，因為它來自未識別的開發者」時：在檔案上按右鍵 →「打開」→「打開」，之後點兩下就可以。終端機問能不能取用「桌面」的檔案時，按「好」。
- 會問一次 commit 上顯示的名字和 email（公開在 GitHub 上，可以用 GitHub 的 noreply 地址），只存在這個資料夾的設定裡。
- 推送時 GitHub 會問帳號和密碼：密碼要貼 GitHub 的 Personal access token，不是登入密碼（github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens，Repository access 選 `kaikou-practice`，Contents 選 Read and write）。Mac 會把它存進鑰匙圈，到期前不用再輸入；需要輸入時，腳本會先說明。

需求：Git（推送用）；跑測試另需 Node.js 20 以上。
